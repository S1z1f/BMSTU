## Разбор задания 1

### Задача.
Сравнить скорость сходимости (число слагаемых для достижения заданной точности $\xi = 10^{-2}, 10^{-4}, 10^{-6}$) следующих разложений числа $\pi$:

$$\pi = 4 \left( 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \dots \right) = 4 \frac{(-1)^n}{2n+1}$$

---

### Вывод формулы для поиска количества слагаемых
Чтобы гарантировать точность $\xi$, должно выполняться условие:

$$\frac{4}{2N+1} \le \xi$$

Выразим $N$ из неравенства:

$$2N + 1 \ge \frac{4}{\xi} \implies 2N \ge \frac{4}{\xi} - 1 \implies N \ge \frac{2}{\xi} - 0.5$$

Округляя полученное значение в большую сторону до ближайшего целого числа, получаем итоговую формулу оценки.

---

### Результаты

* **Для точности $\xi = 10^{-2}$:**
  $$N \ge \frac{2}{0.01} - 0.5 = 199.5 \implies N = 200$$

* **Для точности $\xi = 10^{-4}$:**
  $$N \ge \frac{2}{0.0001} - 0.5 = 19999.5 \implies N = 20000$$

* **Для точности $\xi = 10^{-6}$:**
  $$N \ge \frac{2}{0.000001} - 0.5 = 1999999.5 \implies N = 2000000$$
