Данный ряд является знакочередующимся:
\(\pi =4\sum _{n=0}^{\infty }\frac{(-1)^{n}}{2n+1}=4-\frac{4}{3}+\frac{4}{5}-\frac{4}{7}+\frac{4}{9}-\dots \)
Существует два подхода к решению этой задачи: теоретическая оценка (по теореме Лейбница) и фактический расчет (программный). Рассмотрим оба варианта.

1. Теоретическая оценка (по теореме Лейбница)

Согласно критерию Лейбница, модуль остатка ряда \(R_{N}\) (погрешность после суммирования \(N\) первых членов) не превышает абсолютной величины первого отброшенного члена:
\(|{}R_{N}|{}\le a_{N}=\frac{4}{2N+1}\)
Чтобы гарантированно достичь точности \(\xi \), должно выполняться условие:
\(\frac{4}{2N+1}\le \xi \implies 2N+1\ge \frac{4}{\xi }\implies N\ge \frac{2}{\xi }-0.5\)
Округляя в большую сторону до ближайшего целого, получаем:
• Для \(\xi = 10^{-2}\): \(N \ge 200 - 0.5 = 199.5 \implies \mathbf{N = 200}\)
• Для \(\xi = 10^{-4}\): \(N \ge 20000 - 0.5 = 19999.5 \implies \mathbf{N = 20000}\)
• Для \(\xi = 10^{-6}\): \(N \ge 2000000 - 0.5 = 1999999.5 \implies \mathbf{N = 2000000}\)

2. Фактическое число слагаемых (точный расчет)

Поскольку оценка Лейбница является верхней границей, реальная погрешность ряда Лейбница примерно в два раза меньше и асимптотически равна \(\vert{}R_N\vert{} \approx \frac{1}{N}\).
Если запустить численный алгоритм (например, на Python) и сравнивать текущую сумму с истинным значением \(\pi \), то условие \(\vert{}S_N - \pi\vert{} \le \xi\) выполнится при следующем числе слагаемых \(N\):

Точность (\(\xi \))	Оценка Лейбница (\(a_N \le \xi\))	Фактическое число слагаемых (\(\vert{}S_N - \pi\vert{} \le \xi\))
\(10^{-2}\)	200	100
\(10^{-4}\)	20 000	10 000
\(10^{-6}\)	2 000 000	1 000 000
